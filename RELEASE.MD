# LunaWallet Release Notes

## Highlights (Core Features)
- Create and manage multiple wallets
- View balances and transaction history
- Send and receive funds
- Export/import keys
- Intuitive GUI (sidebar and tabs)

## Feature Details
- Create or restore wallets
- Switch between wallets
- Refresh transaction history
- Send/receive screens
- Key export

## Unique/Notable
- Reward balance calculation and correction
- Sequential reward transaction compression
- Inter-wallet transfers with limits management

## Requirements
- Python 3.11+
- Windows / macOS / Linux

## Notes
- Initial sync may take time
- If the UI doesn't update, restart the app and wait for sync to finish
